#  CondoSys - Sistema de Gestão de Condomínio
> **Projeto Interdisciplinar (PI)** submetido ao Congresso de Tecnologia da Informação, Engenharias e Exatas (CONTEEX 2026-1) da FAM - Centro Universitário das Américas.

## Sobre o Projeto
O **CondoSys** é um software desktop desenvolvido em Java (Orientado a Objetos) para modernizar e automatizar a gestão do Condomínio Residencial Morada Nova. O sistema substitui os antigos cadernos físicos da portaria, oferecendo um controle rigoroso de acesso de visitantes (RBAC) e um fluxo totalmente rastreável para o recebimento e entrega de encomendas.

##  Estrutura do Repositório
 **`/Artigo_Academico`**: Contém o Short Paper (PDF) formatado segundo as normas do CONTEEX, detalhando a arquitetura e conclusões do sistema.
 **`/Codigo_Fonte`**: Ficheiros `.java` contendo a lógica orientada a objetos (Herança, Polimorfismo e Encapsulamento) e o executável final (`.jar`).
 **`/Interface_Telas`**: Capturas de ecrã demonstrando a Interface Gráfica (GUI) construída em Java Swing.
 **`/Modelagem_e_Diagramas`**: Arquitetura base do sistema (Diagrama de Casos de Uso, Diagrama de Classes e Diagrama Entidade-Relacionamento do Banco de Dados).
